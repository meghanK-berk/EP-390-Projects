# Project Title
Reverb patch using Schroeder method that can be controlled by Sensor 

## Installation
Compile the arduino ide
Check if sensor has an output and button is running 1 or 0

## Usage
Set your reverb length prior to clicking button. 
Make sure your volume faders (live.gain) is appropriate.


Click on button to change samples/loops. 0 = no loop.
Play around with the sensor to hear the reverb amount changing.

## Troubleshooting
You can click space bar to see if there are any issues with patch.
