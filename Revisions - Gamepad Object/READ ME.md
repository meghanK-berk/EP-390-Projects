# Revision GamePad Delay Patch

I revised the previous delay patch and added a buffer~ object and waveform~ object to store and recollect data as well as visualize it.

## Installation

Download Max patch
Use a PS controller to control parameters

## Usage
I would use it to make acappella loops, harmonies and ambient pieces that can be manipulated and reversed. 

# features
Game pad left trigger - start audio input and output and delay
Game pad circle trigger - start recording audio to go into buffer. Buffer set to 10000 ms. If you need more time for the recording you may make changes here.
